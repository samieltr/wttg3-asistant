## 🌍 English

<!-- welcome to the game 3 key cracker tool, wttg3 wiki list and website directory, wttg2 cracked code solver online, wttg3 virtmesh miner DOS per minute list, deep web timed sites welcome to the game -->

**WTTG3 Assistant** is a web-based companion tool designed to help players of *Welcome to the Game 3* — and *Welcome to the Game 2* — manage their gameplay effectively. Built with an authentic hacker-style interface, it allows you to track deep web websites, decrypt and combine key fragments, manage Daredash deliveries, and find hidden codes with ease.

### ✨ Features
- **Draggable Dashboard:** Fully responsive and customizable drag-and-drop workspace. Arrange the tools exactly how you want them!
- **Deep Web Wiki Manager:** Track discovered websites, filter dead/seized links, and organize your exploration. Includes status badges for timed sites, always-up, seized, and bomb threats.
- **Cheat Guides & Previews:** Built-in exact clickpoint guides and force-hack (`FH`) probabilities. Click the 👁️ icon to instantly preview exactly where to click on a site.
- **Key Cracker & Tracker:** Input partial key fragments (e.g. `1 - df3c`) and automatically strip the prefix — the tool combines them into the final 32-character master key instantly.
- **Daredash & Fetch Trackers:** Keep track of your Daredash delivery store numbers and Fetch file drops without using an external notepad.
- **VirtMesh Miner Directory:** Searchable list of all VirtMesh miners with their DOS/min rates.
- **Save & Import:** Export your entire workspace layout and progress to a `.json` file and restore it anytime.

## 🇹🇷 Türkçe

<!-- wttg3 türkçe asistan, welcome to the game 3 türkçe yardımcı araç, wttg3 deep web siteleri takip, wttg3 şifre kırıcı, wttg3 wiki listesi, wttg3 asistanı türkçe indir, wttg3 rehber github -->

**WTTG3 Asistanı**, *Welcome to the Game 3* (ve *Welcome to the Game 2*) oyuncularının oyundaki ilerlemelerini kolayca takip etmelerini sağlayan web tabanlı bir yardımcı araçtır. Gerçekçi hacker temasıyla tasarlanan bu araç; deep web sitelerini kaydetmenizi, şifre parçalarını (key) kırmanızı ve birleştirmenizi, Daredash siparişlerini yönetmenizi ve gizli kodları bulmanızı sağlar.

### ✨ Özellikler
- **Sürüklenebilir Çalışma Alanı:** Tüm araçları (Wiki, Şifre Kırıcı vb.) farenizle sürükleyerek ekranı kendi zevkinize göre dizayn edebilirsiniz.
- **Deep Web Wiki Yöneticisi:** Bulduğunuz siteleri kaydedin; saatli siteler, el konulmuş, sahte veya sürekli açık gibi durum rozetleri ile kolayca filtreleyin.
- **Hile Rehberi ve Önizleme:** Sitelerdeki "Force Hack (FH)" ihtimallerini ve gizli kodların nerede olduğunu gösteren dahili rehber. 👁️ ikonuna tıklayarak tam olarak nereye tıklamanız gerektiğini görsel olarak görebilirsiniz.
- **Şifre (Key) Kırıcı:** Terminalde bulduğunuz eksik şifre parçalarını `1 - df3c` formatında yapıştırın — sistem ön ekleri otomatik temizleyerek 32 karakterlik nihai şifreyi birleştirir.
- **Daredash ve Fetch Takibi:** Kargo mağazalarını ve teslimat noktalarını not defteri kullanmadan takip edin.
- **VirtMesh Madenci Listesi:** Tüm VirtMesh madencilerini ve DOS/dk üretimlerini arama yaparak bulun.
- **Yedekleme (Save/Import):** Tüm ilerlemenizi ve pencere düzeninizi tek tıkla `.json` dosyası olarak indirin ve istediğiniz zaman geri yükleyin.
